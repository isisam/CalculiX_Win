# Download and install

Download the stock Windows x64 ZIP and SHA256SUMS from [Releases](https://github.com/isisam/CalculiX_Win/releases). Verify with Get-FileHash -Algorithm SHA256, extract into a writable directory, and retain all licence files. Select ccx.exe as the CalculiX executable in PrePoMax; use a writable work directory and Default/Spooles solver.
