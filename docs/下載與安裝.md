# 下載與安裝

1. 到 [Releases](https://github.com/isisam/CalculiX_Win/releases) 下載 `CalculiX-2.21-stock-win64.zip` 和 SHA256SUMS。
2. 用 PowerShell `Get-FileHash .\CalculiX-2.21-stock-win64.zip -Algorithm SHA256` 比對 SHA256SUMS。解壓到可寫入的短路徑，例如 `D:\CAE\CalculiX`。
3. 保留 LICENSE、LICENSES 與 source 說明。求解器是 Windows x64 程式，不需另裝 Fortran runtime；輸入與輸出資料夾須可寫入。
4. 先跑[範例](使用教學.md)。在 PrePoMax 設定中的 CalculiX executable 選擇 `ccx.exe`；工作目錄選可寫入資料夾。分析步驟採 Default／Spooles，這個 build 沒有 PaStiX／Pardiso。
