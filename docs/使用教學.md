# 使用教學

將 examples 中某個 `.inp` 複製到新的可寫入資料夾，再用 PowerShell 執行：

```powershell
& 'D:\CAE\CalculiX\ccx.exe' -i beamp
```

`-i` 後面是輸入檔基名，不含 `.inp`。確認 console 出現 `Job finished`，並檢查 `.sta`、`.dat`／`.frd` 的有效結果；程序 exit code 不能單獨證明收斂。
在 PrePoMax 匯入 `.inp` 或建立模型、指派材料與邊界條件、建立 analysis 後執行；開啟產生的 `.frd` 查看結果。不同 PrePoMax 版本的設定選單文字可能不同。
可用 `python scripts/verify_stock.py --exe D:\CAE\CalculiX\ccx.exe --work D:\CAE\stock-check-new` 執行三個上游範例；work 必須是新資料夾。
