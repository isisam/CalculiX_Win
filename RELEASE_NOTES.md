# Stock CalculiX 2.21 — Windows teaching build

Pure stock 2.21 numerical solver, built as a static Windows x64 executable with MinGW-w64 GCC 13.2 from WSL/Ubuntu. Windows source portability and libquadmath notices only. Native MSYS2 recipe supplied but not executed. Direct Windows runs passed upstream beamp, beamf (ten ARPACK modes), spring1, matching all checked printed values from Ubuntu CalculiX 2.21.

Download the binary ZIP and verify SHA256SUMS. Corresponding source, dependency/runtime notices and LGPL libquadmath source/relinking recipe are included in the source ZIP. Use Default/Spooles in PrePoMax. See bilingual installation/tutorial/FAQ/issue guides.

Final source tag: v2.21-win64.1. Binary privacy: CLEAN.
